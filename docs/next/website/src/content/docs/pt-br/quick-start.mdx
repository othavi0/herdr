Se o Herdr ainda não está instalado, veja [Instalar o Herdr](/pt-br/docs/install/). Depois, inicie o Herdr a partir de qualquer diretório de projeto:

```bash
herdr
```

O Herdr inicia a sua sessão padrão em segundo plano ou se anexa a ela. Você não gerencia sockets. Se você desanexar (detach), os agentes continuam rodando.

## Criar um workspace

Quando uma sessão não tem workspaces, o Herdr abre um automaticamente. Um workspace é um contêiner no nível do projeto para abas, painéis e agentes. Dê a cada projeto ativo o seu próprio workspace, para que o estado dos agentes fique fácil de ler na barra lateral.

## Usar o mouse

O Herdr é pensado para o mouse, então comece clicando em painéis, abas, workspaces e agentes para focar neles. Arraste as bordas das divisões para redimensionar. Clique com o botão direito para abrir menus de contexto, inclusive para dividir painéis e criar abas. Arraste para selecionar texto e copiá-lo para a área de transferência. Dê um clique duplo em um token para selecioná-lo, ou segure o segundo clique e arraste para estender a seleção por palavras inteiras. Os dois gestos copiam quando você solta o mouse. Copiar não exige Ctrl+C.

Ctrl-clique abre links do painel quando o seu terminal envia o clique com modificador para o Herdr. Isso funciona com hyperlinks OSC 8 e URLs `http://` ou `https://`, inclusive links quebrados em várias linhas cujo início ou fim está fora da área visível. Segure Ctrl e passe o ponteiro sobre um link para sublinhar os trechos visíveis dele. O destaque some quando você afasta o ponteiro, quando o conteúdo do painel muda ou quando o Herdr recebe um evento de soltar o Ctrl. Alguns terminais só informam mudanças de modificador junto com um movimento do mouse. No macOS, use Ctrl-clique para os links de painel que o Herdr trata enquanto a captura do mouse estiver ativa. Cmd-clique só funciona pelo caminho nativo do terminal que contorna o Herdr, como Shift-Cmd-clique ou `ui.mouse_capture = false`.

Se você configurar `ui.right_click_passthrough_modifier`, esse modificador junto com o clique direito envia os gestos de clique direito, segurar e arrastar para os apps do painel que reportam o mouse. Para o clique direito normal ir para o app de um painel, escolha **Send right-clicks to pane** no menu desse painel ou execute `herdr pane input --current --right-click pane` dentro dele. Clique com o botão direito na moldura do painel para abrir de novo o menu do Herdr.

## Executar um agente

Inicie o seu agente de programação em um painel:

```bash
claude
```

Ou `codex`, `pi`, `opencode` ou qualquer outro [agente suportado](/pt-br/docs/agents/). O Herdr detecta o agente automaticamente. Em todos os workspaces, a barra lateral mostra se cada agente está `working`, `blocked`, `done` ou `idle`, então você sempre sabe qual projeto precisa de você.

## Controle pelo teclado

O controle pelo teclado é opcional. O mouse cobre tudo. Pressione `ctrl+b` para entrar no modo de prefixo e depois pressione a tecla de uma ação.

Ações comuns:

| Ação | Tecla |
| --- | --- |
| Dividir à direita | `prefix+v` |
| Dividir para baixo | `prefix+minus` |
| Nova aba | `prefix+c` |
| Próxima aba / aba anterior | `prefix+n` / `prefix+p` |
| Navegar entre workspaces | `prefix+w` |
| Novo workspace | `prefix+shift+n` |
| Desanexar o cliente | `prefix+q` |

Se a ideia de prefixo é nova para você, [Teclado](/pt-br/docs/keyboard/) explica o que ele é, por que os multiplexadores usam um e como usar o Herdr sem prefixo. Pressione `prefix+?` dentro do Herdr para ver todos os atalhos ativos, e `prefix+[` para copiar pelo teclado no modo de cópia.

## Desanexar e voltar

Pressione `prefix+q` ou apenas feche a janela do terminal. O servidor do Herdr e todos os agentes continuam rodando. Execute `herdr` de novo para reanexar à mesma sessão.

Para encerrar a sessão e parar os painéis dela:

```bash
herdr server stop
```

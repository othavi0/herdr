## Escolha o seu caminho

<CardGrid>
  <Card title="Nunca usou um multiplexador de terminal?">
    Você não precisa aprender atalhos para começar. O Herdr é pensado para o mouse. Clique nos painéis, arraste as bordas, divida e alterne pelos menus do clique direito.

    [Início rápido →](/pt-br/docs/quick-start/)
  </Card>
  <Card title="Vem do tmux ou do zellij?">
    Você já conhece o modelo. O prefixo é `ctrl+b`, os painéis persistem, e desanexar (detach) e reanexar funcionam do jeito que você espera.

    [Conceitos →](/pt-br/docs/concepts/) · [Atalhos de teclado →](/pt-br/docs/configuration/#atalhos-de-teclado)
  </Card>
</CardGrid>

## Ou deixe o seu agente apresentar o Herdr

Se você já usa um agente de programação com IA, deixe o onboarding com ele. Cole este prompt:

```text
Help me understand and set up Herdr. Read https://herdr.dev/agent-guide.md first, then walk me through it step by step.
```

O guia cobre os conceitos, a instalação, a configuração e as correções comuns do Herdr, para que o seu agente responda a partir da documentação em vez de improvisar.

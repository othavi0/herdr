O Herdr traz um arquivo de skill de agente reutilizável em [`skills/herdr/SKILL.md`](https://github.com/herdrdev/herdr/blob/master/skills/herdr/SKILL.md).

Instale esse arquivo em qualquer agente de programação que aceite skills reutilizáveis ou instruções personalizadas. A skill ensina o agente a controlar o Herdr de dentro de um painel do Herdr.

O Herdr também serve um guia separado em [`herdr.dev/agent-guide.md`](https://herdr.dev/agent-guide.md) para outra finalidade: um agente que ajuda uma pessoa a aprender, configurar ou resolver problemas do Herdr. A skill é para um agente que opera o Herdr. O guia é para um agente que ensina uma pessoa.

## O que a skill faz

A skill manda o agente usar a CLI `herdr` quando `HERDR_ENV=1` está definida. Isso indica que o agente está rodando dentro de um painel gerenciado pelo Herdr e pode falar com segurança com o socket local do Herdr.

Com a skill instalada, um agente pode:

- inspecionar workspaces, abas, painéis e agentes vizinhos
- dividir painéis e rodar comandos sem roubar o foco
- ler a saída dos painéis e os logs recentes
- esperar servidores, testes ou outro agente terminarem
- iniciar agentes auxiliares em painéis irmãos

A skill é um arquivo de instruções em Markdown para agentes. Se o Herdr já está instalado, rode `herdr --skill` para imprimir a cópia que acompanha aquele binário, na mesma versão.

## Instale

Instale a skill com `npx skills`:

```bash
npx skills add herdrdev/herdr --skill herdr -g
```

Se você instalou a skill quando ela ficava na raiz do repositório, rode esse comando add de novo uma vez, em vez de usar `skills update`. O comando add substitui a cópia grande demais e registra o novo local.

A flag `-g` instala a skill globalmente para os agentes suportados. Omita `-g` para instalá-la no projeto atual.

Use a cópia do repositório como alternativa manual e como fonte de referência:

```text
https://github.com/herdrdev/herdr/blob/master/skills/herdr/SKILL.md
```

Em agentes com sistema de skills, instale esse arquivo como uma skill chamada `herdr`. Em agentes sem sistema de skills, cole o arquivo nas instruções de projeto ou de usuário do agente.

Depois da instalação, inicie o agente dentro do Herdr:

```bash
herdr
claude
```

Ou use qualquer outro agente de programação em um painel do Herdr, para que `HERDR_ENV=1` esteja disponível para o processo do agente.

## Regra de segurança

A skill começa com uma proteção: se `HERDR_ENV=1` não está definida, o agente deve parar e dizer que não está rodando dentro de um painel gerenciado pelo Herdr.

Isso impede que um agente fora do Herdr tente controlar uma sessão que não é dele.
